# Assets de UbiContainer

Coloca aquí las imágenes que usa la app. Archivos esperados:

- `logo.png`            -> Logo usado en el splash y la pantalla de login.
- `login_bg.jpg`        -> Foto de fondo de la pantalla de login (Cristo de la Concordia + contenedor).
- `google_logo.png`     -> Ícono "G" de Google para el botón de login social.

Si alguno de estos archivos no existe, la app muestra un fallback (gradiente verde / íconos)
para no romper la compilación.
